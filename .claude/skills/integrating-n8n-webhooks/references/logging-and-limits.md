# Журнали й ліміти

## Що пишемо в журнал

| Пишемо | Не пишемо ніколи |
|---|---|
| подію, напрям (`n8n.request` / `n8n.callback`), `x-correlation-id` | тіло запиту чи відповіді |
| код статусу, тривалість, номер спроби | ім'я, email, телефон, IP клієнта |
| довжину тіла і його sha256 | токен, підпис, секрет, повний URL з query string |

- Помилку — назвою й кодом (`error.name`, `TimeoutError`), а не об'єктом з тілом чи заголовками.
- Відповіді з помилкою не містять внутрішніх подробиць: стеку, SQL, URL n8n.
- Приклад: `console.info("n8n.request", { event, correlationId, status, attempt, ms })`.

## Ліміти

| Ліміт | Значення | Звідки |
|---|---|---|
| Тіло запиту до вебхука n8n | 16 МБ (`N8N_PAYLOAD_SIZE_MAX`, на self-hosted можна змінити) | документація n8n, Webhook |
| Тіло Server Action | 1 МБ за замовчуванням (`serverActions.bodySizeLimit`) | документація Next.js, Server Actions |
| Відповідь вебхука на n8n Cloud | 100 с, далі 524 | документація n8n, Webhook common issues |
| Тестовий URL | 120 с після «Listen for test event» | документація n8n, workflow development |
| Колбек у Next.js | 64 КБ, вікно часу 300 с | рішення команди |
| Таймаут нашого запиту до n8n | 10 с на спробу, ≤ 2 повтори | рішення команди |

Файли не передаємо — лише посилання на них.
